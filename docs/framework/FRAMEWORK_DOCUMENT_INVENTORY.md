## Canonical source roles

The consolidation uses four source roles:

1. Archival carrier: preserves original wording and provenance.
2. Mathematical foundation: supplies definitions, theorems, and verified
   constructions.
3. Hypothesis source: supplies explicit mechanisms, parameters, observables,
   and falsification criteria.
4. Ideation source: supplies questions and analogies but cannot support a claim.

No statement gains confidence because it appears repeatedly in Alpha001 or in
multiple drafts derived from the same text.

The semantic revision decisions are recorded in
`docs/framework/AETHER_REVISION_RECONCILIATION.md` and
`docs/framework/GENESIS_REVISION_RECONCILIATION.md`.
