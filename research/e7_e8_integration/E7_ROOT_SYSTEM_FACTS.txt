ROOT SYSTEM STRUCTURE
================================================================================

E7 roots live in a 7-dimensional subspace of 8-dimensional space.

ROOT CONSTRUCTION:
The E7 root system can be described as vectors in R^8 satisfying sum(x_i) = 0

Type 1: All permutations of (±1, ±1, 0, 0, 0, 0, 0, 0)
        Subject to: sum of coordinates = 0
        This gives 8×7 = 56 roots

Type 2: All half-integer vectors (±1/2, ±1/2, ..., ±1/2)
        With even number of minus signs
        Subject to: sum of coordinates = 0
        This gives 70 roots

TOTAL: 56 + 70 = 126 roots

ALL E7 ROOTS HAVE THE SAME LENGTH (simply-laced)
Squared length: ||r||^2 = 2 for all roots

RELATIONSHIP TO E8

- E8 has 240 roots in 8-dimensional space

TOTAL: 240 roots

E7 subset: Those E8 roots with coordinate sum = 0
