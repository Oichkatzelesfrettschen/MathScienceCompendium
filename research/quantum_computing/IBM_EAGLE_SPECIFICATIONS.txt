================================================================================
IBM_KYIV SYSTEM
================================================================================

SYSTEM NAME: ibm_kyiv
PROCESSOR TYPE: Eagle r3 (revision 3)
QUBITS: 127
ARCHITECTURE: Heavy hexagon topology

CONNECTIVITY:
- Total CX connections: 288
- Each qubit connected to 2-3 neighbors
- Heavy hexagon pattern optimizes for error rates

BASIS GATES:
- CX: Controlled-NOT (two-qubit gate)
- ID: Identity
- RZ: Rotation around Z-axis
- SX: √X gate
- X: Pauli-X (bit flip)

================================================================================
PERFORMANCE METRICS
================================================================================

TWO-QUBIT GATE FIDELITY: 97.93% (error rate: 2.07%)
READOUT FIDELITY: 98.58% (error rate: 1.42%)

COHERENCE TIMES:
- T1 (relaxation): 70-110 microseconds
- T2 (dephasing): Record T2 = 160 microseconds (exceptional)

GATE TIMES:
- Single-qubit gates: ~35 ns
- Two-qubit CX gates: ~500 ns

================================================================================
ARCHITECTURE DETAILS
================================================================================

QUBIT TYPE: Superconducting transmon qubits
FREQUENCY: Fixed-frequency (not tunable)

3D INTEGRATION:
- Multiple physical levels for wiring
- Reduces qubit crosstalk
- Enables higher qubit density
- Microwave circuit components on separate layers

TOPOLOGY: Heavy Hexagon
- Optimized for error mitigation
- Reduces required SWAP operations
- Balances connectivity vs. coherence

CRYOGENIC OPERATION:
- Operating temperature: ~15 millikelvin
- Dilution refrigerator system
- Magnetic shielding

================================================================================
E7/E8 MAPPING CONSIDERATIONS
================================================================================

127 QUBITS ↔ E7 MAPPING:

Option 1: Direct State Mapping
- Each qubit represents one of 127 states
- 126 states for E7 roots + 1 for zero vector
- Simple but uses all qubits

Option 2: Index Encoding
- Use 7 qubits to index 128 states (127 used)
- Remaining ~120 qubits for:
  * Ancillas for error correction
  * Oracle implementation
  * State verification
  * Grover diffusion operators

Option 3: Amplitude Encoding
- Encode root coordinates as amplitudes
- Requires quantum state tomography
- More complex but uses fewer qubits

PRACTICAL CONSTRAINTS:
- Heavy hexagon topology limits circuit design
- Need to optimize for qubit connectivity
- Error mitigation essential for >100 gate depth
- Measurement correlations due to readout crosstalk

ERROR MITIGATION STRATEGIES
================================================================================

ZERO-NOISE EXTRAPOLATION:
- Run circuits at different noise levels
- Extrapolate to zero noise

PROBABILISTIC ERROR CANCELLATION:
- Inverse noise channels
- Quasi-probability distributions

MEASUREMENT ERROR MITIGATION:
- Calibration matrices
- Correct readout errors

DYNAMICAL DECOUPLING:
- Insert identity-equivalent pulse sequences
- Reduce dephasing during idle times
