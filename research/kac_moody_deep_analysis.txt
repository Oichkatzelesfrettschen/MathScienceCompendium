1.1 DEFINITION: KAC-MOODY ALGEBRAS
-----------------------------------

A Kac-Moody algebra g is a Lie algebra defined by generators and relations
from a generalized Cartan matrix A = (a_ij):

DEFINITION 1.1 (Generalized Cartan Matrix):
A real n x n matrix A = (a_ij) is a generalized Cartan matrix if:
  (i)   a_ii = 2 for all i
  (ii)  a_ij <= 0 for i != j
  (iii) a_ij = 0 implies a_ji = 0 (symmetrizability condition)

DEFINITION 1.2 (Kac-Moody Algebra):
Given a generalized Cartan matrix A, the associated Kac-Moody algebra g(A)
is generated by elements {e_i, f_i, h_i | i = 1,...,n} subject to:
  [h_i, h_j] = 0
  [e_i, f_j] = delta_ij h_i
  [h_i, e_j] = a_ij e_j
  [h_i, f_j] = -a_ij f_j
  (ad e_i)^{1-a_ij}(e_j) = 0  (Serre relations, i != j)
  (ad f_i)^{1-a_ij}(f_j) = 0  (Serre relations, i != j)

CLASSIFICATION THEOREM 1.3:
Kac-Moody algebras are classified by their Cartan matrix determinant:
  - det(A) > 0:  FINITE type (finite-dimensional simple Lie algebras)
  - det(A) = 0:  AFFINE type (infinite-dimensional, one-dimensional center)
  - det(A) < 0:  INDEFINITE type, including:
                 * HYPERBOLIC: All proper principal minors >= 0
                 * LORENTZIAN: Signature (1, n-1)
                 * Other indefinite types

RANK LIMITATION THEOREM 1.4 (Cartan-Killing):
Finite-dimensional simple Lie algebras exist for all ranks.
Affine Kac-Moody algebras exist for all ranks (extensions of finite-dimensional).
Hyperbolic Kac-Moody algebras exist ONLY for rank <= 10.

PROOF SKETCH: For rank >= 11, all indefinite generalized Cartan matrices have
at least one proper principal minor < 0, violating the hyperbolic condition.
This is established by explicit enumeration and matrix analysis.

CONSEQUENCE: E_10 is the MAXIMAL hyperbolic extension of E_8.
